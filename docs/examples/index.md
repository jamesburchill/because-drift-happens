# Examples

This directory contains conceptual examples for Because Drift Happens. These are not production designs or implementation templates.

The examples are intended to show how drift, checkpoints, intervention, and observability can be described in plain operational terms.

## Practise After Reading

Try the [Guided Exercise](../guided-exercise.md) to identify intent, assess evidence, establish authority, and choose a proportionate response. Write your own answer before opening the suggested response.

## Example Guidelines

Examples should:

- Be short and concrete.
- Avoid private, client, or confidential details.
- Avoid vendor promotion.
- Separate signal, interpretation, decision, and action.
- Show how coherence is preserved or repaired.
